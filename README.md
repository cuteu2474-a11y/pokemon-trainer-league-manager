# 포켓몬 트레이너 리그 매니저

트레이너 구단을 운영하는 HTML·JavaScript 기반 싱글플레이 경영 게임입니다. 단장은 영입·육성·편성·출전 순서를 관리하고, 트레이너 AI가 포켓몬의 기술과 교체를 판단합니다.

## 현재 상태

플레이 가능한 개발 버전입니다. 우리 구단 경기는 Showdown 5인 연승전으로 계산하고 관전·순위 반영까지 연결돼 있습니다. 다른 구단끼리의 라운드당 19경기는 간이 계산을 사용합니다.

포켓몬은 레벨 대신 체력·공격·방어·특수공격·특수방어·스피드 각각의 CA/PA를 사용합니다. 구형 훈련·시장 평가 등 일부 기능은 이 체계로 연결하는 작업이 남아 있습니다.

[게임 실행](https://pokemon-trainer-league-manager.vercel.app)

앞으로 할 작업과 게임 규칙은 **개발 작업 목록에서만 관리**합니다. 규칙을 문서에 확정한 것과 게임 코드에 적용한 것은 구분합니다.

구단 메뉴의 **재정·계약**에서 시즌 연봉, 주간 지급 내역, 계약 만료와 재계약, 미지급금을 확인할 수 있습니다. 기존 저장에는 도입 주차 이전의 급여를 소급 청구하지 않습니다.

공식 경기는 출전 확정 후 같은 선수단·난수 시드로 계산·재시도하며, 정산 시 다른 탭의 진행과 중복 지급을 검사합니다. 결과 반영에는 Web Locks를 지원하는 브라우저가 필요합니다.

경기 준비에서 대회 규정을 확인할 수 있습니다. 무승부·300턴 제한은 양쪽 주자 탈락으로 처리하며, 이어싸움에는 남은 수면과 소모 도구·보호 형태도 인계합니다.

## 로컬 실행

Node.js 20 이상에서 저장소 전체를 준비한 뒤 실행합니다.

```bash
npm ci
npm run dev
```

브라우저에서 http://127.0.0.1:8000 을 엽니다. HTML 파일만 열면 경기 API를 사용할 수 없습니다. 이미지와 데이터 파일도 필요하므로 `index.html`만 복사하지 마세요.

로컬 서버는 `/api/match`, `/api/opponent-scout`, `/api/trainer-moves`를 연결합니다. 로컬 실행과 Vercel 배포 검증은 구분합니다.

## 검사 명령

```bash
npm run check:web
npm test
```

명령과 테스트 범위는 [Showdown 연동](docs/SHOWDOWN_INTEGRATION.md#검증)을 참고하세요. 과거 테스트 개수를 최신 통과 결과로 사용하지 않습니다.

## 저장소 구조

- `index.html`, `assets/`: 운영 화면·로고·경기 관전·훈련·탐색 UI
- `api/`, `src/web/`: 경기·상대 분석·기술 연구 API와 데이터 변환
- `src/battle/`: 전투, AI 탐색, 연승전, 로그 집계
- `src/core/`: 능력치·성장 계산과 이전 체계의 호환 코드
- `src/league/`, `src/scouting/`: 리그와 상대 분석
- `tests/`: 단위·통합 검사
- `docs/`: 기획·현황·개발·기술 문서

`main` 브랜치에서 작업하며 문서 정리를 이유로 새 브랜치나 자동 워크플로를 만들지 않습니다. 비공식 포켓몬 팬게임입니다.

경기 준비에서 주자별 메가진화·Z기술·다이맥스·테라스탈 방식과 대상을 등록할 수 있습니다. 강화권은 주자당 한 단체전에서 1회이며, 연승 중 다시 지급되지 않습니다. 관전에 남은 사용권과 실제 발동을 표시합니다.

원래 등록한 6마리가 공통 타입을 가진 전문 편성에는 공격·방어·특공·특방 +5%를 한 번 적용합니다. HP·스피드와 CA/PA는 유지하고, 폼 변경·변신·AI 탐색에도 같은 규칙을 사용합니다. 상대 분석과 관전에서 적용 여부를 확인할 수 있습니다.
