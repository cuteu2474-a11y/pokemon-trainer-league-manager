# 게임 개요

갱신일: 2026년 10월 27일

세부 규칙과 개발 순서는 [개발 작업 목록](DEVELOPMENT_TODO.md), 현재 구현 범위는 [구현 현황](ui-integration-status.md)에서 관리합니다. 이 문서는 게임의 역할과 진행 구조를 설명합니다.

## 단장의 역할

포켓몬 트레이너 구단의 단장으로 영입·육성·계약·편성·출전 순서를 관리합니다. 기술이나 교체를 매 턴 직접 선택하지 않습니다.

단장은 전술과 행동을 권고하고, 트레이너는 선호 전술·판단 능력·감독 신뢰에 따라 수용·절충·거부합니다. 이 자율성과 관계 변화가 게임의 중심입니다.

체육관과 관장 중심 구조 대신 마을·도시를 기반으로 한 구단끼리 경쟁합니다. 단일 타입 편성은 의무가 아닙니다.

## 경기와 리그

- 1~4부, 각 10구단으로 구성합니다.
- 같은 부의 다른 9구단과 홈·원정으로 18라운드를 치릅니다.
- 구단마다 트레이너 5명, 각자 포켓몬 6마리를 출전시킵니다.
- 승리한 주자는 잔존 전력으로 다음 상대와 계속 싸우고, 패배한 주자는 다음 트레이너로 교체됩니다.
- 다음 상대에게 생존 포켓몬의 HP를 최대 HP의 10%만큼 회복합니다. 기절 개체는 부활하지 않으며 PP·상태를 이어받습니다.
- 시즌 종료 시 상위·하위 2구단이 인접 부로 승격·강등합니다. 1부 상위와 4부 하위에는 해당 방향의 이동이 없습니다.
- 우승 후에도 다음 시즌을 계속 운영합니다.

무승부·턴 제한·특수 강화·상태 인계·전문 타입 보너스의 세부 기준은 [확정 규칙](DEVELOPMENT_TODO.md#4-확정-규칙과-구현-기준)을 따릅니다.

## 선수단과 육성

트레이너는 본인이 포획한 포켓몬을 사용하며 이적할 때 보유 포켓몬 전체가 동행하는 구조입니다. 출전 명단과 보유 명단, 소유권 검증을 연결하는 작업이 남아 있습니다.

포켓몬의 6개 능력치에는 각각 현재 능력 CA와 성장 상한 PA가 있습니다. 레벨과 별도 IV·EV 육성 수치는 사용하지 않습니다. 종족값·성격과 현재 CA로 실제 전투 능력치를 계산하고, PA는 성장 한계로만 사용합니다.

탐색·포획은 지역과 조건에 맞는 종을 확보하는 활동이고, 개체 감별은 같은 종 안에서 우수한 CA/PA를 발견하는 능력입니다. 트레이너의 전투 판단·포획·육성 능력은 구분합니다.

## 운영 흐름

1. 다음 일정과 계약·선수단·재정 상태를 확인합니다.
2. 훈련·회복·탐색 방침을 정하고 필요한 영입을 진행합니다.
3. 상대 분석과 미팅을 거쳐 출전 순서를 확정합니다.
4. 자동 경기를 관전하고 실제 행동·활약·성장 피드백을 확인합니다.
5. 다음 경기 준비에 결과를 반영합니다.
6. 시즌 결산·승강·계약·은퇴·신인 배출을 처리합니다.

원하는 속도로 진행하는 싱글플레이이며 실제 시간 대기는 없습니다. 빠른 일정 진행과 기본 주간 방침 유지는 구현 예정입니다.

## 개발 방향

현재 우선순위는 이적시장 정보 통일, 첫 경기까지의 반복 조작 감소, 경기 전후 피드백 연결, 모바일 메뉴 정리입니다. 새로운 기능 수보다 단장의 선택과 실제 결과가 연결되는지를 먼저 확인합니다.

부별 전력은 시즌 수만으로 자동 상승시키지 않습니다. 장기 운영은 영입·성장·은퇴·재정·세대교체에서 선택이 생기도록 구성합니다.

은퇴·진화·보유 상한·경제 수치는 이 문서에 중복 기재하지 않고 개발 작업 목록의 확정 규칙을 따릅니다.
