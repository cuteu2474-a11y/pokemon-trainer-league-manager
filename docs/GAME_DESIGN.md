# 포켓몬 트레이너 리그 매니저 — 게임 기획서 v1.0

작성일: 2026-10-23

## 1. 콘셉트와 플레이어 역할

- 가칭: **Pokémon Trainer League Manager**
- 장르: 포켓몬 턴제 배틀 + FM식 구단 경영 + KOF식 연승 단체전
- 플랫폼: HTML/JavaScript, 모바일과 PC 대응, 싱글플레이
- 플레이어 역할: 트레이너 구단의 **단장**. 기술 선택이나 포켓몬 교체를 직접 수행하지 않음
- 장기 목표: 4부에서 시작하여 승격, 1부 우승, 은퇴와 세대교체를 극복하는 장기 운영
- 체육관, 체육관 관장, 단일 타입 의무는 폐지. 독립된 **트레이너 구단** 간 리그를 진행

## 3. 리그 구조

**제안 기준:** 각 부 10개 구단, 총 40개 구단. 각 부에서 다른 9개 구단과 홈·원정으로 총 18라운드를 진행합니다.

| 리그 | 승격 | 강등 |
| --- | --- | --- |
| 1부 | 없음(1위 우승) | 하위 2구단 |
| 2부 | 상위 2구단 | 하위 2구단 |
| 3부 | 상위 2구단 | 하위 2구단 |
| 4부 | 상위 2구단 | 없음 |

- 승점: 승리 3점, 패배 0점, 공식 무승부 시 1점씩(동시 전멸 등 특수 상황은 세부 규칙 필요).
- 동률 기준 제안: 승점 → 트레이너 격파 득실 → 추가 기준 또는 순위 결정전.
- AI 구단도 계약, 영입, 육성, 은퇴, 구단 재정을 사용하며 독립적으로 로스터를 변화시킵니다.
- 부별 전력 예산/상대 수준은 고정 범위를 따르고 시즌 수에 따라 무한히 상승하지 않습니다. 승격·강등된 특정 구단의 전력 격차는 가능하며 이후 재정·계약 규칙으로 완화합니다.
- 1부 우승 뒤에도 게임이 종료되지 않고 다음 시즌으로 이어집니다.

## 4. 경기 형식: 5인 KOF식 연승 단체전

1. 양 구단은 트레이너 5명과 각자 출전 포켓몬 6마리, 출전 순서를 미리 등록합니다.
2. 양쪽 선봉 트레이너가 자동 6대6 싱글배틀을 치릅니다.
3. 포켓몬 6마리가 전부 기절한 트레이너가 탈락합니다. 패배한 구단의 다음 트레이너가 출전합니다.
4. 승리한 트레이너는 잔존 포켓몬 전력으로 계속 대결합니다.
5. 상대 구단 트레이너 5명을 모두 탈락시키면 단체전에서 승리합니다. 올킬과 역올킬이 가능합니다.

### 다음 트레이너 대결로 넘어갈 때

- **회복:** 생존 포켓몬은 최대 HP의 10%만큼 회복하고 최대 HP를 초과하지 않습니다.
- 기절한 포켓몬은 부활하지 않습니다.
- 생존 포켓몬의 잔여 HP, 사용한 기술 PP, 독/마비/화상 등 지속 상태이상은 유지합니다.
- 능력치 랭크 변화와 날씨, 설치기, 일시 필드 효과는 새 대결 시작 시 초기화합니다.
- 별도의 편성 보너스는 해당 트레이너의 출전 6마리 기준으로 다시 적용합니다.
- 전체 단체전이 종료된 뒤에는 다음 공식 라운드를 위한 일반 회복·훈련 단계가 진행됩니다.

### 타입 보너스

- 단일 타입 강제 없음. 복합 타입도 포함하여 출전 6마리가 공유하는 타입이 하나라도 있으면 전문 편성으로 인정합니다.
- 보너스는 해당 트레이너의 포켓몬에 적용하고, 날씨·원작 필드 기술과는 구별합니다.
- 적용 능력치, 보너스 크기, 중복 규칙은 **미확정**입니다. 공격/특수공격/방어/특수방어 +10% 등은 초기 비교용 가설이며 밸런스 테스트 전까지 확정 수치가 아닙니다.

## 5. 구단 경영 시스템

### 트레이너

- 스카우트 보고서(실력·잠재력에 추정 오차), 계약 기간, 연봉, 이적료, 보너스, 출전 기대 역할
- 기술 선택, 교체 판단, 상대 예측, 전술 이해, 위기 대응, 포켓몬 육성 능력
- 교육, 실전, 멘토링을 통한 성장, 전성기 및 이후 경력 관리
- 선봉~대장 출전 순서와 담당 포켓몬 배정

### 포켓몬

- 원작 종족값·타입 상성·개체값(IV)·노력치(EV)·성격·특성·기술·진화·도구를 토대로 구현
- 영입, 육성, 기술 조정, 진화, 스카우트, 트레이너 배정
- 세대교체를 위한 은퇴 제도(구체적인 종족별 시기와 성능 영향은 미확정)
- 구단 소유로 관리해 트레이너 이적 시 임의로 포켓몬이 사라지지 않도록 하는 방안을 **제안**함. 최종 소유권 규칙은 별도 확정 필요

### 경제와 시설

- 리그 성적·후원·흥행 수입, 트레이너 연봉·계약금·시설 유지비·훈련비 지출
- 훈련 시설, 스카우트 센터, 회복 시설, 유망주 육성 시설
- 승격 후에도 무리한 지출이 지속 가능하지 않도록 예산·계약 시스템 설계

## 6. 자동 전투 AI

- 플레이어는 기본적으로 개별 턴의 기술이나 교체를 직접 선택하지 않습니다.
- 트레이너 AI가 합법적인 행동 후보를 만들고 상성, 예상 피해, KO 확률, 속도, 위험, 교체, 상태이상, 장기 전개를 평가합니다.
- 낮은 능력치가 명백히 무효인 기술 반복이나 무한 교체처럼 부조리한 행동을 뜻하지 않게 합니다.
- 상위 능력치 트레이너는 상대 예측 정확도, 위험 관리, 몇 턴 앞을 내다보는 전략에서 이득을 얻습니다.
- 단장은 사전 전술과 경기 중 공격적·안정적·전개형 등의 **작전 방침**을 변경할 수 있지만, A안에 따라 개별 행동을 강제 선택하지 않습니다.
- AI 구단도 같은 배틀 엔진과 정보 접근 규칙을 따릅니다. 상대의 미공개 기술·도구를 선험적으로 아는 치팅은 사용하지 않습니다.
- 배틀 로그와 재현 가능한 난수 시드로 이상한 판단과 밸런스 문제를 검증합니다.

## 7. 시즌과 진행 루프

**제안:** 1시즌은 게임 내 1년으로 간주합니다. 18라운드에 충분한 준비·훈련 기간을 배치하고, 시즌 종료 후 이적시장·계약 갱신·은퇴·승격/강등 처리를 진행합니다.

1. 시즌 시작: 목표, 예산, 계약, 스카우트, 선수단 정비
2. 라운드 준비: 상대 분석, 포켓몬 육성, 출전 5명·각 6마리와 순서 확정
3. 경기 진행: KOF식 AI 자동 전투, 관전·속도 조절·빠른 결과 보기
4. 결과: 승점·순위·기록·재정·경험·회복 반영
5. 시즌 결산: 승강, 계약 만료, 포켓몬 은퇴, 새로운 세대 영입

실제 시간 대기 없이 원하는 만큼 일정을 진행하는 싱글플레이로 설계합니다.
