# 트레이너 시스템

갱신일: 2026년 10월 27일

현재 코드의 자율 판단과 경력 구조를 설명합니다. 구현할 규칙과 수정 항목은 [개발 작업 목록](DEVELOPMENT_TODO.md)에서 관리합니다.

## 능력·성향·신뢰의 구분

| 구분 | 역할 |
| --- | --- |
| 판단 능력 | 기술·교체·전황·자원 관리의 정확성과 탐색 범위 |
| 선호 전술 | 균형·공세·견제·유지력·속공 중 기본 운영 방향 |
| 선호 플레이 | 특정 상황에서 우선 검토하는 행동 성향 |
| 개방성·소신 | 감독 권고를 받아들이는 방식 |
| 감독 신뢰 | 권고 반응과 경기 후 관계 변화 |
| 실전 경력 | 실제 출전·행동·성과에 따라 누적되는 경험 |

선호 플레이가 기술 위력이나 명중률을 직접 올리는 것은 아닙니다. 행동 선택과 우선순위에 영향을 줍니다.

## 현재 전투 능력치

[전투 자율성 코드](../src/battle/battle-autonomy.js)는 다음 값을 사용합니다. 이전 저장에 개별 값이 없으면 기존 전술·교체 능력에서 보완합니다.

| 능력 | 필드 |
| --- | --- |
| 기술 판단 | `moveJudgment` |
| 교체 판단 | `switchJudgment` |
| 전황 분석 | `battleAnalysis` |
| 전력 관리 | `resourceManagement` |

탐색·포획, 개체 감별, 기초 훈련, 기술 지도, 잠재력 개발, 컨디션 관리는 운영 기능의 역할입니다. 모든 화면과 계산이 하나의 능력치 구조로 통일된 상태는 아닙니다. 특히 탐색의 기존 `skill/captureSkill`과 새 기획의 역할 대응, 자율 훈련의 CA/PA 연결이 남아 있습니다.

## 권고와 경기 진행

1. 단장이 전술 또는 특정 행동을 권고합니다.
2. 트레이너는 선호 전술·개방성·소신·분석 능력·감독 신뢰를 기준으로 반응합니다.
3. 수용하면 해당 권고를 반영하고, 절충하면 자기 전술과 함께 일부 검토하며, 거부하면 자기 판단을 유지합니다.
4. 실제 기술·교체는 합법적인 행동 후보 중 AI가 선택합니다.
5. 경기 결과 확정 후 신뢰와 실전 경험을 반영합니다.

전술 권고와 행동 권고의 반응은 따로 기록합니다. 수용했다는 사실만으로 원하는 행동이 실제로 일어나거나 승리를 보장하지 않습니다.

## 구현된 선호 플레이

[선호 플레이 코드](../src/battle/trait-decision.js)에 등록된 일곱 종류입니다.

| 선호 플레이 | 행동 방향 |
| --- | --- |
| 킬각 포착 | 처치 가능성이 있는 공격 기회 검토 |
| 적극적인 교체 | 불리한 대면에서 교체 검토 |
| 상성 교체 전문가 | 유리한 후속 포켓몬 선택 |
| 에이스 보존 | 연승을 위한 핵심 전력 보존 |
| PP 관리자 | 기술 PP의 장기 사용 고려 |
| 상태이상 전문가 | 실제로 효과가 있는 상태이상 검토 |
| 전황 분석가 | 상대 행동 후보와 가상 전투 비교 |

현재 경력 처리는 성공한 행동의 근거와 누적 성향을 사용합니다. 권고를 전달했다는 이유만으로 선호 플레이를 지급하지 않습니다. 이전 문서의 추가 선호 플레이 후보와 1~3개 제한은 현재 적용 규칙으로 사용하지 않습니다.

## 포켓몬과 경력

- 포획자 전속 사용, 보유 명단과 출전 명단 분리, 이적 시 전체 동행은 [확정 규칙](DEVELOPMENT_TODO.md#4-확정-규칙과-구현-기준)을 따릅니다.
- 현재 이적은 트레이너 객체와 포켓몬·경력·성향을 함께 이동합니다. 고유 개체 ID와 포획자 검증은 추가 연결이 필요합니다.
- 포켓몬의 CA/PA와 트레이너의 판단 능력·잠재력 표시는 다른 지표입니다. 이적시장 평가에서 혼용하지 않아야 합니다.
- 경기 후 변화는 실제 출전과 행동을 근거로 표시합니다. 미출전 주자에게 활약을 생성하지 않습니다.
- 은퇴·계약 종료와 장기 기록 보존은 개발 작업 목록의 기준에 맞춰 통합합니다.
