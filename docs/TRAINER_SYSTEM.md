# 트레이너 능력치·포켓몬 전속 사용권·선호 플레이 설계 v0.3

작성일: 2026-10-23

> 이 문서는 **확정 규칙**과 **개발 제안**을 구분합니다. 아래의 선플 목록·수치·훈련 방식은 아직 확정되지 않았습니다.

## 1. 확정 규칙

1. 지역 탐색 임무로 포켓몬을 확보합니다.
2. 기존 `탐색`과 `포획 기술`을 하나의 **`탐색·포획`** 능력치로 통합합니다.
3. **`탐색·포획`은 종의 발견 능력입니다.** 다양한 포켓몬 종을 만나고, 종족값이 높은 종을 조우할 가능성이 커집니다.
4. **`개체 감별`은 실제 개체의 질에 영향을 줍니다.** 같은 종이라도 높은 현재 능력(CA)·잠재 능력(PA)을 지닌 개체와 조우할 가능성이 커집니다. 보고서 정확도만 높이는 능력치가 아닙니다.
5. **전통적인 IV 대신 FM식 CA·PA를 사용합니다.** CA는 성장 가능한 현재 능력이고, PA는 개체별 성장 한계입니다. 높은 감별 능력이 이미 확보한 개체의 값을 사후 변경하지는 않습니다.
6. **자기가 잡은 포켓몬은 자기만 사용합니다.** 포켓몬은 포획자 ID를 가지며, 다른 트레이너의 출전 6마리에 편성될 수 없습니다. 포획자 본인은 여섯 마리를 초과하여 보유할 수 있으나 경기에는 여섯 마리를 선택합니다.
7. 트레이너마다 FM식 **선호 플레이(선플)** 시스템을 도입합니다. 선플이 능력치를 직접 높이는 버프가 아니라 행동 선호를 바꾸도록 설계합니다. 구체적인 목록 및 밸런스는 이후 확정합니다.

## 2. 트레이너 능력치 제안 — 10종, 각 1~20

| 분야 | 능력치 | 주된 역할 |
| --- | --- | --- |
| 배틀 | 기술 판단 | 공격·보조·상태이상 기술의 상황별 가치 평가 |
| 배틀 | 교체 판단 | 교체 타이밍과 후속 포켓몬 선택 |
| 배틀 | 전황 분석 | 상대 기술과 교체·전술 예측 |
| 배틀 | 전력 관리 | HP·PP·상태이상·KOF식 연승 지속력 관리 |
| 포획 | **탐색·포획** | 다양한 종의 발견 확률 및 종족값이 높은 포켓몬 종의 조우 확률 |
| 포획 | **개체 감별** | 같은 종 안에서 높은 CA·PA를 가진 우수 개체의 조우 확률 |
| 육성 | 기초 훈련 | 경험치·훈련 진척 등 CA 성장 과정의 효율. EV의 별도 사용 여부는 미확정 |
| 육성 | 기술 지도 | 기술 구성과 전술 적응 훈련 |
| 육성 | 잠재력 개발 | 포켓몬이 가진 원래 성장 가능성의 활용 |
| 육성 | 컨디션 관리 | 피로·회복·경기 준비 상태 관리 |

능력치가 낮아도 명백한 타입 무효 기술을 무한 반복하는 등의 비상식적인 AI 행동은 금지합니다. 종족값은 종의 고유 속성으로 유지하고, 개체 감별은 포획 전 우수 개체의 **발견 확률**에만 관여하며 이미 포획한 개체의 CA·PA를 변경하지 않습니다.

### 포켓몬 CA·PA 설계

- **현재 능력(CA):** 당장 발휘할 수 있는 전투 역량. 훈련 및 경기 경험 등의 성장 요인으로 변화할 수 있습니다.
- **잠재 능력(PA):** 개체별 성장 상한. 포획 시 확정하고 이후 일반적인 훈련으로는 증가하지 않습니다. `CA ≤ PA`를 유지합니다.
- **종족값:** 어떤 종인지에 따른 전투 특성의 기초. `탐색·포획`이 높은 트레이너는 종족값이 높은 종을 만날 확률이 높지만, 같은 종의 종족값 자체를 수정하지 않습니다.
- **개체 감별:** 같은 종의 조우 결과에서 우수한 CA·PA 조합이 뽑힐 가능성에 영향. 특히 높은 PA는 장기 육성의 가치가 있지만 높은 PA가 곧바로 높은 CA를 의미하지는 않습니다.
- **미확정:** CA·PA의 숫자 범위, PA 추첨 분포, 초기 CA 결정, 종족값과 CA를 실제 전투 능력치로 변환하는 공식, 기존 EV 등의 훈련 수치와 결합 방식. FM의 1~200 범위는 검토용 참고일 뿐 아직 채택하지 않았습니다.

## 3. 선플의 역할

- **능력치 = 판단의 정확성 / 행동 효율**, **선플 = 판단이 비슷하게 유효할 때 우선하는 전략**.
- 기본 AI가 먼저 합법적이고 합리적인 후보를 추린 다음, 선플에 맞는 후보의 선택 성향을 조정하는 방식이 좋습니다.
- 출전 순서와 단장 전술의 영향을 받되, 선플 때문에 아예 통하지 않는 기술을 고집하거나 무의미한 반복 교체를 하지는 않습니다.
- 선플은 약점이 되기도 합니다. 예컨대 속공 선호가 장기전 상대에게 불리할 수 있으므로 무조건 좋은 특성만 있는 구조는 피합니다.

## 4. 선플 초안 — 배틀 분야

| 선플 | 선호하는 행동 | 고려할 불리함 |
| --- | --- | --- |
| 속공 지향 | 빠르게 체력을 깎고 압박하는 기술 | 장기전 준비가 부족할 수 있음 |
| 장기전 지향 | 회복·방어·자원 보존 | 즉시 처치 기회를 놓칠 수 있음 |
| 적극적인 교체 | 불리한 상성에서 빠르게 교체 | 설치기 등에 취약해질 수 있음 |
| 교체 자제 | 현 포켓몬으로 해결할 방안 우선 | 불리한 대면 유지 가능성 |
| 상태이상 활용 | 독·마비·화상 등 축적 효과 고려 | 상대 내성에 따라 가치 저하 |
| 강화기 활용 | 안전한 타이밍에 능력치 상승 기술 | 지나친 준비로 턴을 낭비할 위험 |
| 에이스 보존 | 핵심 포켓몬의 HP·PP를 후속 대결용으로 관리 | 당장 승리하는 데 필요한 화력 손실 |
| 과감한 예측 | 상대 교체나 특정 기술을 예상한 선택 | 예측이 틀릴 때 손해 |

## 5. 선플 초안 — 탐색·포획 및 육성 분야

| 선플 | 선호하는 행동 | 고려할 불리함 |
| --- | --- | --- |
| 희귀종 우선 | 드문 포켓몬 발견·포획 시도에 자원 집중 | 전체 포획 수량 감소 가능 |
| 다수 포획 | 폭넓게 여러 포켓몬 확보 | 개체 선별에 쓸 시간 부족 |
| 우수 개체 선별 | 보고 결과를 비교하고 고잠재 개체에 집중 | 빠른 선수단 확대에 불리 |
| 주력 집중 육성 | 특정 포켓몬에 훈련 시간 배분 | 로스터 전체의 균형 약화 |
| 균형 육성 | 보유 포켓몬에 훈련을 고르게 배분 | 에이스 성장 속도는 느릴 수 있음 |
| 기술 연구 선호 | 다양한 기술 조합·전술을 훈련 | 순수 기초 훈련 시간 감소 |

**제안하는 상충 관계:** `속공 지향`↔`장기전 지향`, `적극적인 교체`↔`교체 자제`, `희귀종 우선`↔`다수 포획`, `주력 집중 육성`↔`균형 육성`. 상충 선플 동시 보유 여부는 구현 전 결정합니다.

## 6. 데이터와 계약상 주의사항

- 각 포켓몬에 `capturedByTrainerId`를 기록하고, 경기 등록·출전·자동 교체의 모든 경로에서 동일한 포획자만 사용 가능한지 검증합니다.
- 임무에서 포획한 포켓몬을 다른 트레이너에게 옮기는 기능은 제공하지 않습니다.
- **확정:** 트레이너가 다른 구단으로 이적하거나 계약 만료로 구단을 떠나면 자신이 포획한 포켓몬 전부를 데려갑니다. 포켓몬 소속 구단은 트레이너의 새 소속에 맞춰 함께 변경되며, 포획자 ID는 그대로 유지합니다. 이전 구단에는 해당 포켓몬이 남지 않고 복제도 발생하지 않습니다.
- **미확정:** 트레이너 은퇴 시 전속 포켓몬의 처리는 추후 결정합니다.
- **제안:** 선플은 개인별 1~3개 정도로 시작하고 훈련·멘토링·실전 경험을 통해 습득/교체할 수 있게 합니다. 정확한 제한·습득 난이도는 밸런스 후 확정합니다.
- 단장 지시와 선플이 충돌할 경우 우선순위를 명시하고, 경기 로그에 선택 근거를 남겨 자동 AI가 답답하게 보이지 않게 합니다.

## 7. 검증 기준

1. 트레이너 A가 포획한 포켓몬은 A만 출전 가능하고 B는 출전 명단에 넣을 수 없습니다.
2. 같은 지역·동일 조건에서 `탐색·포획` 점수가 높아지면 반복 임무의 종 다양성과 높은 종족값의 종 조우 비중이 증가하지만 특정 종의 포획을 보장하지 않습니다.
3. 같은 종·동일 조건에서 `개체 감별` 점수가 높아지면 반복 임무의 우수 CA·PA 개체 조우 비중이 증가합니다. 포획이 완료된 개체의 CA·PA는 감별 점수 변화로 소급 변경되지 않습니다.
4. 동일 포켓몬·상대·난수 조건에서 선플 유무에 따른 선택 성향 차이가 관측되면서도 불법·명백히 무효인 행동은 발생하지 않습니다.
