# 웹게임 통합 기준 버전 (2026-10-26)

## 포함된 코드

- `index.html`: 최신 구단 선택·운영 화면 및 확정된 14개 구단 로고.
- `assets/ui/`: HTML에서 분리한 대용량 이미지 12개. index.html만 따로 다운로드하면 이미지가 빠지므로 저장소 전체로 실행합니다.
- `src/`, `tests/`: 기존 Showdown 전투·AI·5인 연승전·리그 코드를 같은 main에 보존했습니다.
- `package-lock.json`: 전투 엔진과 하위 의존성 버전을 고정하여 `npm ci`로 재현합니다.
- `npm run dev`: http://127.0.0.1:8000 로컬 정적 서버.
- `npm run check:web`: HTML 끝부분, 인라인 스크립트 문법, 이미지 경로, 엔진 파일 존재 검사.

## 확인 결과

- 이미지 파일 12개를 다시 인라인으로 넣으면 최신 전달본 `trainer_league_jangmak_rock_pillars_applied.html`과 바이트 내용이 일치합니다. UI나 로고를 다시 덮어쓸 필요가 없었습니다.
- `npm test`: 기존 40개 테스트 모두 통과.
- `npm run check:web`: 인라인 스크립트 8개, 이미지 파일 12개 검사 통과.
- 로컬 HTTP로 index.html 및 이미지 12개의 응답 내용을 원본 파일과 비교하여 일치 확인.
- 로컬 서버의 숨김 경로 차단 및 없는 파일의 404 응답 확인.
- 브라우저 바이너리 다운로드 실패로 실제 화면 클릭·레이아웃 및 이어하기의 브라우저별 동작 검증은 미완료입니다.

## 다음 단계: 실제 전투를 화면에 연결

현재 HTML의 경기 버튼은 간이 전력 시뮬레이션을 사용합니다. `src/battle/showdown.js` 및 `src/league/season.js`의 실제 전투를 화면에서 호출하지 않습니다. 하나의 저장소에 코드를 모은 것을 실제 전투 연결 완료로 간주하지 않습니다.

다음 작업은 UI 선수단과 엔진 선수단 형식을 맞추고, 출전 순서와 전투 결과를 화면·순위표·저장 상태에 연결하는 것입니다. 현재 테스트는 전체 시즌의 빠른 시뮬레이션과 일부 실제 Showdown 경기를 포함하며, 실제 엔진으로 시즌 360경기를 모두 검증한 것은 아닙니다.

배포 서비스의 자동 배포 여부와 배포 URL은 이번 검증에 포함하지 않았습니다.
