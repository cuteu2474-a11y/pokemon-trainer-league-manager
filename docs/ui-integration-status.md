# 경기 준비 및 Showdown 연결 현황 (2026-10-26)

## 경기 진행 흐름

1. 경기 주차로 넘어가는 버튼은 항상 경기 준비 화면을 엽니다. 준비를 취소하면 주차·경기 결과가 바뀌지 않습니다.
2. 구단 피로·사기와 트레이너별 전술/교체 능력, 포켓몬 6마리의 이름·레벨을 확인합니다. 기존 저장에는 개인 컨디션이 없어 미측정으로 표시합니다.
3. 트레이너 5명의 순서를 바꿔 확정하면 `/api/match`에서 실제 Showdown 5인 연승전을 계산합니다. 상대 구단은 현재 등록 순서로 출전합니다.
4. 계산 완료 후 해당 경기 기록을 자동 재생합니다. 포켓몬 출전·기술·기절·HP 변화·트레이너 교체를 보고 일시정지, 속도 변경, 결과까지 보기를 사용할 수 있습니다. Showdown 원본 그래픽 클라이언트가 아닌 게임 내 관전 화면입니다.
5. 경기 결과 확인 버튼을 누르면 해당 주차를 진행하고 순위표·경기 기록·저장에 반영합니다. 같은 결과를 재반영할 수 없습니다.

준비 상태와 계산 완료 결과는 저장하며 새로고침 시 준비 화면 또는 관전으로 복구됩니다. 계산 중 새로고침하면 준비부터 재시도합니다. API 실패 시 주차와 순위는 그대로 유지하며 간이 결과로 대체하지 않습니다.

## 선수단 변환

- 화면에 등록된 실제 트레이너와 포켓몬 30마리를 사용합니다. 별도 생성 선수단으로 바꿔치기하지 않습니다.
- 명시적인 species/CA/PA/GP/기술/특성/도구가 있으면 사용합니다.
- 이전 시제품의 포켓몬은 레벨·전력만 보유합니다. 전력을 CA로 읽고 기존 `gpBudget`을 6개 스탯에 균등 배분하며, 기본 특성과 타입 기반의 기본 기술을 자동 편성합니다. 이 기본 기술은 원작 등장인물의 공식 기술 구성이라는 의미가 아닙니다. 준비 화면에도 이 사실을 표시합니다.
- 한국어 종명→도감 번호는 PokeAPI 다국어 종명 CSV에서 가져왔습니다: https://github.com/PokeAPI/pokeapi/blob/master/data/v2/csv/pokemon_species_names.csv . 기존 저장의 일본어 별칭 ‘뉴라’는 포푸니로 해석합니다.
- 실제 피해·상성·특성·도구·상태이상과 연승전의 HP/PP/상태 계승 및 생존 포켓몬 HP 10% 회복은 기존 Showdown 엔진이 처리합니다.

## 실행 및 확인

`npm ci`, `npm run dev` 후 http://127.0.0.1:8000 에서 실행합니다. Vercel에서는 `api/match.js`가 Node 경기 함수입니다. 실제 배포 검증은 별도입니다.

- 기존 테스트와 새 웹 경기 API 테스트 44개 통과.
- 실제 Chromium에서 준비 진입·순서 변경·확정→Showdown 계산→관전→결과 반영 확인.
- 준비 화면 새로고침 시 순서 유지, 실패 응답 시 주차/라운드 보존, 관전 새로고침 후 결과 복구 및 결과 저장 검증.
- 다른 구단끼리의 19경기는 기존 간이 계산을 유지합니다. 실제 엔진으로 시즌 360경기 전체를 검증한 상태가 아닙니다.
- 개인 컨디션의 장기 관리와 경기 성능 반영은 미구현입니다. 그래픽 관전 화면은 아래 시각적 경기 관전 항목을 참고하세요.

## 시각적 경기 관전

- 경기장과 양측 포켓몬의 앞/뒤 스프라이트, 레벨·HP·상태이상, 남은 포켓몬 수, 트레이너 출전 진행을 표시합니다.
- 실제 `move`, `-damage`, `-heal`, `switch`, `faint`, `-formechange`, `-transform`, 날씨 기록에 맞춰 공격 이동·타입별 투사체·피격·회복·교체·기절을 표현합니다. 명중이나 피해량은 화면에서 새로 계산하지 않습니다.
- 스프라이트는 Pokémon Showdown의 공개 이미지 서버를 사용하며, 실패 시 PokeAPI/sprites의 애니메이션·정지 이미지로 순차 대체합니다. 이미지 실패가 경기 진행을 막지 않습니다.
- `species-sprites.json`은 PokeAPI의 pokemon.csv에서 가져온 이미지 번호 목록입니다. 폼별 이미지도 구분합니다: https://github.com/PokeAPI/pokeapi/blob/master/data/v2/csv/pokemon.csv .
- 중계 기록은 접어두고 전장을 중심으로 관전합니다. 기존 일시정지·배속·결과까지 보기·결과 저장을 유지합니다.
- 최신 서버 이전에 저장된 경기 기록도 종 이름으로 스프라이트를 찾아 재생할 수 있습니다.


## 전술 및 관전 흐름 개선

- 경기 준비에서 트레이너마다 균형·공세·견제·유지력 전술을 선택합니다. 순서 변경 후에도 해당 트레이너의 선택을 유지하며, 확정 경기 요청과 결과 저장에 전달합니다.
- 명시적 기술 세트가 없는 저장은 Showdown의 종별 전체 learnset에서 기술을 고릅니다. 공세는 공격/능력 상승, 견제는 상태이상/견제, 유지력은 회복을 우선하며 모든 전술에 공격 수단을 확보합니다. 원작 등장인물의 공식 기술 구성으로 주장하지 않습니다. 세대 간 학습 가능 목록을 사용하며 별도 레벨별 습득 제한은 아직 적용하지 않습니다.
- AI는 기존 실제 턴 탐색 결과에 작은 전술 선호를 더해 동점에 가까운 선택을 구분합니다. 기술 자체의 위력·확률·상성·능력치나 연승전 규칙은 변경하지 않습니다.
- 주요 장면 관전을 기본으로 제공하며 전체 관전으로 전환할 수 있습니다. 중요한 장면이 없는 턴도 내부 상태·기록·활약 집계는 빠짐없이 반영합니다. 교체, 기절, 급소, 상태이상, 폼 변경, 큰 피해와 낮은 HP 상황은 해당 턴을 재생합니다.
- 양 구단 트레이너 5명의 상대 포켓몬 기절 수와 트레이너 대결 승리 수를 실시간 표시합니다. 연승과 마지막 주자 등장, 경기 종료 시 최다 격파를 표시합니다. 미리 계산된 최종 활약을 관전 중 선공개하지 않습니다.
- 기술 한국어 이름은 PokeAPI `move_names.csv` 및 `moves.csv`를 사용합니다: https://github.com/PokeAPI/pokeapi/tree/master/data/v2/csv .

## 판세·선수단·경기 보고서

- 양쪽 현재 주자의 포켓몬 6마리를 고정 슬롯으로 표시합니다. 각 슬롯의 HP·기절·상태이상과 출전 중인 포켓몬을 구분합니다. 트레이너가 바뀌거나 승자가 이어 출전할 때 실제 초기 상태를 받아 복구합니다. 이전 버전 기록에서 확인할 수 없는 벤치 HP는 미확인으로 표시합니다.
- 같은 종의 포켓몬이 여러 마리인 경우 경기 내부 이름을 슬롯별로 구분합니다. 화면과 보고서는 원래 이름을 표시합니다. 능력치·기술·판정에는 영향을 주지 않습니다.
- 마지막 포켓몬 위기, 급소, 전멸, 연승, 동점·역전을 실제 진행 상태로 강조합니다. 승자가 이어 출전하면 기존 최대 HP 10% 회복 규칙을 중계에 표시합니다.
- 상성·잔여 HP·독/화상·회복 기록에 맞춰 짧은 중계를 제공합니다. 관전 중 다음 주요 장면으로 이동해도 지나간 상태와 활약은 모두 처리합니다.
- 경기 종료 후 양 구단의 상위 직접 공격 활약을 보여줍니다. 서버가 실제 HP 감소와 기절 기록을 집계하며, 독·날씨 같은 간접 피해를 특정 포켓몬의 직접 피해로 추정하지 않습니다.
- 감독실/일정에서 지난 경기 활약 보고서를 다시 열 수 있습니다. 관전 새로고침 후 결과를 확인할 때 구단 화면이 숨겨진 채 남던 문제도 수정했습니다.
- 실제 초깃값과 슬롯 구분, 직접 피해와 간접 피해 분리에 대한 검사 포함 로컬 테스트 47개 통과.

## 실시간 기술·상성 및 이어싸움 인계 수정

- 전장 양쪽에 현재 포켓몬의 기술 4개, PP, 타입, 물리/특수/변화 구분, 위력·명중을 표시합니다. 현재 상대의 타입을 기준으로 공격 기술 배율을 계산합니다. 변화 기술에는 공격 배율을 붙이지 않습니다. 이 표는 기본 타입 상성이며 특성·도구 및 기술별 특수 판정에 따른 최종 피해 예측은 아닙니다.
- 엔진이 전달하는 현재 타입·실제 기술 슬롯·현재/최대 PP를 기록으로 받습니다. 프레셔의 추가 PP 소모, 변신 등으로 바뀐 기술 슬롯을 사용 횟수로 추정하지 않습니다. 변하지 않은 상태는 중복 기록하지 않습니다.
- 이어 출전하는 주자는 기절 개체 수·생존 개체 수와 HP 회복, PP·상태이상 인계를 명시합니다. 펼쳐서 각 포켓몬의 이전 HP→현재 HP 및 실제 회복량, PP 합계를 확인할 수 있습니다. 최대 HP 10% 회복 시 HP 상한을 적용하며 기절한 개체는 회복하지 않습니다.
- 실제 상태 인계 오류도 수정했습니다. Showdown은 교체 시 `side.pokemon` 배열 순서를 바꾸므로, 종료 상태를 그 배열 인덱스로 읽으면 다른 포켓몬의 HP·PP가 원래 슬롯에 붙었습니다. 전투 시작 시 포켓몬 객체의 원래 순서를 보존하고 동일 객체에서 종료 상태를 읽도록 고쳤습니다.
- 서로 다른 종을 섞고 실제 교체·기절이 발생한 연승전에서, 기절 개체 HP 0과 각 개체의 PP가 다음 대결에 그대로 이어지는 회귀 검사 및 프레셔 PP 검사 포함 로컬 테스트 49개 통과.
- 새로 계산하는 경기부터 새 기술 상태 기록과 수정된 인계를 사용합니다. 이전에 계산·저장한 전투 결과를 소급 재계산하지 않습니다.

### 기술명 한국어 통합
- `moves-ko.json`은 Showdown의 전체 기술 ID를 한국어로 매핑합니다. PokeAPI 기술 번호와 엔진 ID를 대응해 Z기술·`visegrip` 별칭 누락을 보완하고, 거다이맥스 기술명과 PKHeX 한국어 리소스의 `니힐레이저`를 추가했습니다. CAP 창작 기술은 `(창작)`으로 구분합니다.
- 관전 화면이 같은 사전을 직접 읽어 기술 패널·공격 알림·중계 기록에 적용합니다. 기존에 저장한 경기의 영어 label도 한국어 사전이 우선하므로 재계산 없이 이름이 바뀝니다. 전투 엔진의 기술 ID와 판정은 그대로 사용합니다.
