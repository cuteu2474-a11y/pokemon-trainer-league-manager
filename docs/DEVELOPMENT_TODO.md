## 1. 우선 수정

### 훈련과 능력치 연결
- [ ] 자율 훈련에서 이전 종합 CA·PA·GP 대신 능력치별 CA·PA를 사용하도록 수정
- [ ] 주간 훈련과 AI 구단 훈련의 기존 전투력 상한을 능력치별 PA 상한으로 변경
- [ ] 훈련 방향에 따라 해당 능력치의 CA가 성장하도록 연결
- [ ] 훈련 보고서에 실제 CA 변화 표시
- [ ] 저장 후 다시 접속해도 같은 주의 훈련 효과가 중복 적용되지 않는지 확인

관련 코드: [자율 훈련](../assets/matchday.js), [능력치 처리](../assets/ability-ui.js), [CA·PA](../src/core/stat-potential.js)

### 기술 구성과 출전 자격
- [ ] 선수단 생성과 기술 연구에 동일한 종별 기술 습득 기준 적용
- [ ] 경기 등록 시 기술 습득 가능 여부와 특성·도구 사용 조건 검사
- [ ] 포켓몬에 고유 ID와 포획한 트레이너 ID 부여
- [ ] 포획한 트레이너만 해당 포켓몬을 출전시킬 수 있도록 검사
- [ ] 이적과 계약 종료 시 포켓몬·소유자 정보가 유지되는지 확인

관련 코드: [선수단 생성](../src/league/pokemon-rosters.js), [경기 등록](../src/web/match-service.js), [탐색·포획](../assets/pokemon-expedition.js)

### 레벨 제거 후 특수 기술 처리
- [ ] 일격기와 셸암즈 등 내부에서 레벨을 참조하는 기술 확인
- [ ] 남은 기술에 레벨 없는 리그 규칙 적용
- [ ] 실제 경기와 AI의 가상 전투에 동일한 규칙 적용
- [ ] 변신·폼 변경·혼란·고정 피해가 새 능력치 체계에서 정상 작동하는지 확인

관련 문서: [레벨 없는 전투 규칙](level-free-ca-pa.md)

## 2. 남은 기능

### 리그 전체 경기
- [ ] 다른 구단끼리의 경기도 Showdown 연승전으로 계산
- [ ] 경기 계산 진행률 표시와 중단 후 재시도 지원
- [ ] 재시도 시 이미 완료한 경기 결과 재사용
- [ ] 주차·순위·경기 결과가 중복 반영되지 않도록 처리
- [ ] 웹과 별도 리그 엔진의 점수·동률·승강 처리 통일

현재 웹은 우리 구단 경기만 실제 전투로 계산하며, 나머지 19경기는 간이 계산을 사용합니다.

### 컨디션과 일정
- [ ] 트레이너·포켓몬별 피로와 회복 관리
- [ ] 경기 준비 화면에 개인 컨디션과 파견 상태 표시
- [ ] 확정된 파견·출전 규칙에 따라 훈련과 경기 일정 충돌 처리
- [ ] 단체전 도중 HP 10% 회복과 다음 공식 경기 전 회복을 구분하여 처리

### 탐색·포획과 개체 감별
- [ ] 현재 탐색·포획 능력치 구성을 기획과 대조해 정리
- [ ] 탐색·포획 능력에 따른 종별 발견 확률 반영
- [ ] 개체 감별 능력에 따른 같은 종 내 CA·PA 분포 반영
- [ ] 화면에 표시한 발견·포획 확률과 실제 결과 확인
- [ ] AI 구단의 탐색·포획 연결

관련 문서: [트레이너 능력치 설계](TRAINER_SYSTEM.md)

### 보유 포켓몬과 출전 명단
- [ ] 트레이너별 보유 포켓몬 명단과 출전 6마리 분리
- [ ] 새 포켓몬을 등록할 때 기존 포켓몬을 바로 방출하지 않고 보관할 수 있도록 수정
- [ ] 출전 명단 저장과 포획자 확인 연결
- [ ] 이적 시 보유 포켓몬 전체가 동행하도록 처리

현재 탐색에서 포획한 포켓몬은 기존 6마리 중 하나를 방출하고 교체하는 방식입니다.

### 진화와 전투 세트
- [ ] 확정된 진화 조건을 레벨 없는 성장 체계에 적용
- [ ] 진화 후에도 개체 ID·포획자·CA·PA·육성 기록 유지
- [ ] 기술·특성·도구를 확인하는 화면과 실제 경기 데이터 연결
- [ ] 특성·도구로 인한 무효 효과를 기본 타입 상성과 구분해 표시

### 은퇴·계약·재정
- [ ] 은퇴와 신예 생성 과정에 능력치별 CA·PA 적용
- [ ] 계약 만료·은퇴 후 출전 공석과 후보 승격 처리 점검
- [ ] 트레이너와 포켓몬의 경력·은퇴 기록 보존
- [ ] 여러 시즌의 수입·연봉·이적료·훈련비·탐색비 점검
- [ ] 시즌 경과에 따른 전력과 자산의 과도한 상승 여부 확인
