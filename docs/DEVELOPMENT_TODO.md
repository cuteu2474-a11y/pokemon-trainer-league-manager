#### 출전 선수단 확정과 결과 반영 보호

##### 화면과 흐름

경기 준비 → 출전 순서·포켓몬 확인 → 출전 확정 → 경기 계산 → 관전 → 결과 반영 순서로 진행합니다.

- 확정 전에는 편성을 바꿀 수 있습니다. 선수단이 변경되면 준비 화면도 갱신하고 출전 자격을 다시 확인합니다.
- 확정 후 계산·관전·결과 반영이 끝날 때까지 해당 경기에 등록된 트레이너의 이적·방출·포켓몬 편성·세트 변경을 막습니다. 버튼 옆에 “경기 결과 확인 후 변경할 수 있습니다”라고 표시합니다.
- 확정 직전에 진행 중이던 기술 연구 등 비동기 응답도 등록된 세트를 뒤늦게 바꾸지 못하게 합니다. 해당 작업을 먼저 정산하거나 경기 종료 후 적용할 대상으로 보관합니다.
- 이 제한은 우리 구단뿐 아니라 해당 경기의 상대 구단에도 적용합니다.
- 계산 실패 시 같은 확정 선수단으로 재시도할 수 있습니다. 편성을 바꾸려면 확정을 해제하고 준비 화면으로 돌아갑니다.
- 관전을 건너뛰어도 같은 경기 결과를 적용합니다. 새로고침을 이유로 선수단이나 난수 시드를 새로 뽑지 않습니다.

##### 저장과 검증

출전 확정 시 현재 선수단과 별도로 경기용 사본을 저장합니다.

| 저장 항목 | 내용 |
| --- | --- |
| 경기 식별 | 시즌, 라운드, 양 구단 ID, 경기 ID |
| 출전 정보 | 트레이너 ID와 출전 순서, 포켓몬 ID와 포획자 |
| 전투 입력 | 종·폼, 개별 CA/PA, 성격, 기술·PP 기준, 특성, 도구, 적용할 컨디션 |
| 계산 기준 | 난수 시드, 대회 규정 버전, 전투 엔진 버전, AI 전술·판단에 필요한 설정 |
| 진행 상태 | 준비·확정·계산·관전·반영 완료, 선수단 변경 버전 |

경기 API는 확정한 사본으로 계산합니다. 결과에는 경기 ID와 입력을 식별할 값을 포함합니다. 브라우저는 현재 대기 중인 경기와 일치하는 결과만 받습니다.

결과 확인 시에는 다음을 확인한 뒤 순위·수입·경험·기록을 함께 반영합니다.

- 현재 시즌·라운드가 해당 경기와 일치하는지
- 선수단이 확정 후 변경되지 않았는지
- 같은 경기 결과가 이미 반영되지 않았는지

일치하지 않으면 일부 보상만 지급하지 않고 반영을 중단합니다. 저장을 복원했거나 다른 탭에서 선행 진행한 경우에도 같은 검사를 사용합니다. 저장 자체가 실패하면 완료로 표시하지 않고 재시도할 수 있게 합니다.

### 대회 예외 규정

#### 먼저 정할 내용

현재 연승전은 무승부가 나오면 양쪽 트레이너를 다음 주자로 교체합니다. 전투 턴 제한을 넘으면 계산 오류를 반환합니다. 이 두 처리를 구분하여 규정으로 정리합니다.

| 상황 | 정할 내용 |
| --- | --- |
| 동시 전멸·전투 무승부 | 양쪽 주자 탈락 여부, 격파 점수, 마지막 주자끼리 무승부일 때 단체전 결과 |
| 턴 제한·진행 불가 | 제한 턴 수, 제한 도달 시 무승부 또는 판정 방식, 반복 교체·회복 처리 |
| 특수 변신 | 메가진화·Z기술·다이맥스·테라스탈 각각의 허용 여부와 사용 횟수 단위 |
| 소모 도구 | 다음 상대에게 소모 상태를 유지할지, 공식 경기 종료 후 복구할지 |
| 일회성 효과 | 특성·기술의 사용 이력을 새 상대에게 유지할지 초기화할지 |
| 전투 상태 | 수면·맹독의 내부 진행값 등 상태별 인계 범위 |

HP·PP·상태이상 인계, 기절 유지, 생존 포켓몬의 최대 HP 10% 회복은 기존 확정 규칙을 유지합니다. 새로운 판정승이나 특수 변신 제한은 이 문서만으로 확정하지 않습니다.

#### 구현 방식

- 경기 준비 화면에 “대회 규정”을 펼쳐 볼 수 있게 합니다. 허용 변신, 턴 제한과 인계 규칙을 짧게 표시합니다.
- 규정은 한 데이터에서 읽고 실제 전투·AI 가상 전투·관전 설명에 함께 사용합니다.
- 전투 결과에 종료 이유를 저장합니다. 정상 승리·무승부·규정 판정·계산 실패를 구분합니다.
- 서버 시간 초과나 통신 실패를 경기 패배로 처리하지 않습니다.
- 인계가 필요한 도구·일회성 효과·상태 내부값은 HP·PP와 함께 개체 ID 기준으로 저장합니다.
- 규정 변경 전 경기에는 당시 규정 버전을 남깁니다. 이미 완료한 경기의 결과를 새 규정으로 소급 변경하지 않습니다.

#### 재정 화면

현재 잔액, 이번 시즌 수입·지출, 앞으로 지급할 확정 비용과 지급일을 표시합니다. 아직 확정되지 않은 수입은 예상 수입으로 구분합니다.

자금이 부족한 거래는 실행 전에 비용과 부족액을 보여주고 중단합니다. 자동 정산 지출은 확정한 적자 처리 규칙에 따라 적용합니다. 일부만 차감한 뒤 거래가 실패하는 상태는 만들지 않습니다.

대응 수단은 현재 제공하는 제도에 연결합니다. 가능한 경우 지출 축소, 신규 영입 보류, 이적 협상 등을 안내합니다. 대출·승점 삭감·강제 매각·해임은 별도 합의 없이 추가하지 않습니다.

#### 시즌 목표와 평가

- 시즌 시작 시 소속 부, 선수단 수준과 재정에 맞는 목표를 보여주고 해당 시즌 기준을 저장합니다.
- 목표는 리그 성적, 선수 육성, 재정 관리로 구분합니다.
- 시즌 중 선수가 이적하거나 성적이 바뀌었다는 이유로 목표를 몰래 변경하지 않습니다.
- 결산에는 목표·실제 결과·평가 이유를 나란히 표시합니다.
- 육성 평가는 단순 훈련 횟수 대신 실제 CA 성장과 신인 활용을 확인합니다. 평가 비중과 보상 수치는 별도로 정합니다.
- 초기에는 평가 보고서를 제공합니다. 자금 보상·후원 변화·해임과 연결하려면 효과와 기준을 먼저 확정합니다.

#### 완료 기준

- [ ] 거래 취소·재시도·새로고침으로 돈이 중복 지급·차감되지 않음
- [ ] 예정 비용과 실제 정산 내역이 일치함
- [ ] 잔액이 부족할 때 가능한 대응과 진행 조건을 알 수 있음
- [ ] 같은 시즌 목표와 결과에는 같은 평가가 나옴
- [ ] 부당한 재정 제재나 미확정 보상이 자동 적용되지 않음

- 구단 기록: 각 부 최종 순위, 승점, 승무패, 트레이너 격파 득실, 우승·승격·강등
- 트레이너 기록: 출전 단체전 수, 주자 대결 수, 승무패, 올킬, 최다 연승
- 포켓몬 기록: 실제 출전 횟수, 직접 공격 격파 수, 활약 기록
- 경기 목록: 날짜 또는 주차, 상대, 점수, 종료 이유와 요약 보기

트레이너·포켓몬 프로필에서도 개인 경력을 열 수 있게 합니다. 이적·은퇴 후에도 당시 소속과 성적이 남습니다.

#### 집계와 보존

- 경기 결과 반영 때 경기 ID를 기준으로 한 번만 집계합니다.
- 출전 명단에만 있고 실제로 나서지 않은 주자는 출전 기록을 올리지 않습니다.
- 올킬은 한 트레이너가 같은 단체전에서 상대 주자 5명을 모두 탈락시켰을 때 기록합니다. 포켓몬 5마리 격파와 구분합니다.
- 직접 공격과 독·날씨 등 간접 피해는 기존 활약 보고서의 집계 기준을 따릅니다. 확인되지 않은 격파를 임의로 귀속하지 않습니다.
- 시즌 종료 시 최종 순위와 승강 결과를 보관한 뒤 새 시즌 집계를 시작합니다.
- 구단·트레이너·포켓몬 ID와 당시 표시 이름·소속을 함께 저장합니다. 이름 변경이나 이적이 과거 기록을 바꾸지 않습니다.
- 요약 기록은 장기 보존하고 용량이 큰 상세 전투 로그는 별도로 관리합니다. 로그가 없어도 점수와 시즌 성적을 볼 수 있게 합니다.
- 과거 저장에 기록이 없으면 “기록 없음”으로 표시합니다. 추정 출전 수나 가상 경기 로그를 만들지 않습니다.

#### 완료 기준

- [ ] 새 시즌 시작 후 이전 시즌 순위·우승·승강 기록 조회 가능
- [ ] 미출전 주자와 실제 출전 주자의 기록을 구분
- [ ] 이적·은퇴·동명이인·같은 종의 여러 개체를 구분
- [ ] 개별 경기 합계와 시즌·개인 집계가 일치
- [ ] 저장·복원 후에도 기록이 유지되고 중복 집계되지 않음

### 중요 알림함

#### 화면

감독실 상단에 읽지 않은 알림 수와 “알림함”을 표시합니다. 알림함에는 제목·발생 주차·대상·요약·확인 버튼을 둡니다.

| 알림 | 이동할 화면 |
| --- | --- |
| 계약 만료 예정·재계약 필요 | 해당 트레이너 계약 |
| 은퇴 예고·은퇴 결정 | 트레이너 또는 포켓몬 경력 |
| 탐색 완료·포획 후보 등록 대기 | 해당 트레이너 탐색 결과 |
| 기술 변경·주요 CA 성장 | 훈련 결과와 포켓몬 상세 |
| 이적 제안·협상 결과 | 해당 제안 또는 이적 기록 |
| 재정 부족·출전 공석 | 재정 또는 선수단 |
| 경기·시즌 결산 | 해당 경기 보고서 또는 기록실 |

일반 훈련 결과는 주간 요약 한 건으로 묶습니다. 버튼을 누르면 해당 대상을 선택한 상태로 이동합니다.

#### 상태와 중복 처리

- 알림에 원인 사건 ID를 부여하고, 같은 사건을 다시 처리해도 알림을 추가 생성하지 않습니다.
- 읽음과 처리 완료를 구분합니다. 계약 알림을 읽었다고 재계약이 끝난 것으로 처리하지 않습니다.
- 기한이 지났거나 선수가 이적한 경우 “기한 종료”, “소속 변경”처럼 현재 상태를 표시합니다.
- 대상이 사라진 과거 알림은 요약을 보여줍니다. 잘못된 다른 선수를 열지 않습니다.
- 알림창이 매주 자동으로 튀어나오지 않게 합니다. 출전 불가나 저장 실패처럼 진행에 직접 영향을 주는 문제만 관련 화면에서 알립니다.

#### 완료 기준

- [ ] 새로고침해도 같은 알림이 반복 생성되지 않음
- [ ] 읽음·미처리·기한 종료 상태가 저장됨
- [ ] 알림에서 올바른 대상과 관련 화면으로 이동
- [ ] 과거 알림이 게임 진행을 막지 않음

### 첫 시즌 안내

#### 표시 방식

별도 장문의 설명창 대신 처음 사용하는 화면에 짧은 안내를 붙입니다.

| 시점 | 안내 내용 |
| --- | --- |
| 첫 감독실 | 다음 경기와 이번 주 활동 확인 |
| 첫 선수단 확인 | 트레이너 5명·각 6마리와 포획자 제한 |
| 첫 능력치 확인 | CA는 현재 능력, PA는 해당 능력치의 성장 상한 |
| 첫 훈련 | 단장 권고와 트레이너 자율 판단 |
| 첫 탐색 | 지역·서식지·시간대, 발견 확률과 포획 확률의 차이 |
| 첫 경기 준비 | 출전 순서와 선수단 확정 |
| 첫 연승 | 기절 유지, 생존 포켓몬 HP 10% 회복, PP·상태 인계 |
| 첫 시즌 종료 | 기록실과 승강 결과 |

- 안내는 한 번에 한 주제만 보여줍니다. “다음”, “건너뛰기”, “다시 보기”를 제공합니다.
- 안내를 읽는 것만으로 주차를 진행하거나 돈을 쓰거나 출전을 확정하지 않습니다.
- 완료한 안내 단계는 저장합니다. 기존 저장에서는 처음부터 강제 실행하지 않습니다.
- 기능을 아직 사용할 수 없는 시점에는 해당 안내를 열지 않습니다.
- 도움말에서 원하는 주제만 다시 열 수 있게 합니다.

#### 완료 기준

- [ ] 모든 안내를 건너뛰어도 정상 진행 가능
- [ ] 안내 도중 새로고침해도 실제 활동이 중복 실행되지 않음
- [ ] 기존 저장을 열 때 첫 시즌 안내가 강제 실행되지 않음
- [ ] 모바일에서 조작 버튼과 핵심 정보를 가리지 않음
