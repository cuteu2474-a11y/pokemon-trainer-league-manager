# 전투 능력치 적용

갱신일: 2026년 10월 27일

파일명과 일부 코드의 `GP` 명칭은 이전 구조에서 남은 이름입니다. 현재 전투 입력은 **6개 능력치별 CA/PA**이며 레벨·종합 GP 예산으로 전투 스탯을 계산하지 않습니다.

## 적용 순서

1. [stat-potential.js](../src/core/stat-potential.js)에서 입력을 검증하거나 기존 저장을 능력치별 CA/PA로 변환합니다.
2. [gp-adapter.js](../src/battle/gp-adapter.js)의 `convertPokemon`이 종족값·현재 CA·성격으로 실제 능력치를 계산한 뒤, 전문 편성이면 공격·방어·특공·특방에 5%를 한 번 적용합니다. HP·스피드는 그대로입니다.
3. [gp-battle-stream.js](../src/battle/gp-battle-stream.js)의 `packGPTeam`이 리그 전용 필드와 레벨을 제거하고 Showdown 팀 문자열을 만듭니다.
4. 전투 인스턴스의 시작 함수에서 첫 턴 전에 `injectBattleTeams`를 실행합니다.
5. `storedStats`, `baseStoredStats`, 최대 HP와 스피드 값을 적용하고, 이어싸움이면 개체별 잔여 HP·PP·상태를 복원합니다.
6. 전투 시작 때 원래 포켓몬 객체 순서를 보존해 교체 후에도 같은 개체의 종료 상태를 읽습니다.

포장 과정의 IV=31·EV=0은 호환용 기본값입니다. 그 값으로 계산한 원본 능력치를 리그 전투 스탯으로 사용하는 구조가 아닙니다.

## 폼 변경과 변신

- 종 변경 후 새로운 종족값과 같은 개체 CA·성격으로 스탯을 다시 계산합니다.
- 폼 변경 전 받은 피해량을 보존하고 새 최대 HP 범위를 적용합니다. 기절한 개체를 되살리지 않습니다.
- 변신은 상대의 실제 전투 스탯을 복사하는 원본 처리를 사용하며 HP는 복사하지 않습니다.
- 영구 폼·도구 소모·수면 진행·소모된 보호 형태를 개체별로 인계합니다. 단체전 통합 강화권과 메가·테라·스텔라 소모 이력도 인계하며, 다이맥스는 대결 종료 시 정상 해제합니다. 전문 타입 자격은 원래 등록 6마리로 고정하며, 폼 변경 때 새 스탯에 한 번 적용하고 변신은 상대 실제 스탯을 그대로 복사합니다. 자세한 기준은 [개발 작업 목록](DEVELOPMENT_TODO.md#4-4-전문-타입-편성-보너스)을 따릅니다.

## 확인할 경계

초기 주입이 맞더라도 폼 변경·변신·AI 복제·상태 인계 뒤에 원본 스탯으로 돌아가는지 확인해야 합니다. 각 경로가 같은 능력치 계산을 사용해야 하며, 개체 순서가 바뀌어도 HP·PP가 다른 개체에 붙으면 안 됩니다.

검사 파일과 실행 명령은 [Showdown 연동](SHOWDOWN_INTEGRATION.md#검증)에 있습니다.
