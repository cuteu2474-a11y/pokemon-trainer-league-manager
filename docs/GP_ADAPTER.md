# 독자 GP 능력치 → Showdown 전투 객체 변환

- `convertPokemon`은 원작 종족값, 레벨, 성격 보정, CA/PA/GP를 받아 전투 능력치를 계산합니다. IV·EV는 사용하지 않습니다.
- `injectBattleStats`는 전투 객체 생성 후, **첫 턴 이전**에 실제 능력치를 주입하는 저수준 함수입니다.
- Showdown은 기본적으로 IV/EV에서 스탯을 다시 계산하므로 팀 직렬화만으로는 독자 GP가 적용되지 않습니다.
- HP와 `storedStats`, `baseStoredStats`를 설정합니다. 변신·폼체인지·능력치 재계산 등은 엔진 내부에서 스탯을 덮어쓸 수 있어 별도 검증과 추가 후킹이 필요합니다.
- **현재 제한:** 실제 `@pkmn/sim` 전투 시작 생명주기에 어댑터를 연결하지 않았습니다. 따라서 `simulateSixVsSix` 호출만으로 GP가 적용되지는 않습니다.
- 단위 테스트는 작성했으나 실행 확인 전입니다. Showdown 버전별 실제 전투 객체 호환성도 미검증입니다.
