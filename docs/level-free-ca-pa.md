# 레벨 없는 포켓몬 전투 및 능력치별 CA/PA — 리그 전용 규칙

## 확정된 데이터 모델
- 포켓몬 레벨은 게임 데이터, 성장 과정 및 리그의 능력치·일반 공격 피해 계산에서 사용하지 않는다.
- hp(체력), atk(공격), def(방어), spa(특공), spd(특방), spe(스피드)는 각각 statCA(현재 능력)와 statPA(잠재 상한)를 갖는다. 범위는 1~200이며 CA≤PA.
- PA는 공격·방어·속도 등의 전투 결과에 직접 영향을 주지 않고 CA 성장의 상한만 정한다.
- 포켓몬 종족별 원본 기본 능력치·성격·기술·상성·특성·도구·날씨·상태이상·급소 규칙은 Showdown 처리를 유지한다.

## 리그 전용 엔진 산식 — 최초 밸런스 기준
- HP = floor(0.80 × 종족 HP + 0.95 × HP CA + 45)
- 다른 스탯 = floor((0.80 × 해당 종족 기본 스탯 + 0.70 × 해당 스탯 CA + 10) × 성격 배율)
- 껍질몬 최대 HP는 1로 유지.
- 일반 기술 기본 피해 = trunc(trunc(trunc(28 × 기술 위력 × 공격 스탯) / 방어 스탯) / 50).
- 기존 Showdown의 (2 × Level / 5 + 2) 항을 28이라는 게임 전체 공통 계수로 교체한 리그 패치다. 이후 원본의 STAB, 타입 효과, 날씨, 급소 등 후속 피해 처리 절차는 보존한다.
- 혼란 자해도 계수 28을 적용한다. 나이트헤드·지구던지기 고정 피해는 50, 사이코웨이브는 25~75 피해를 사용한다.
- 연승전 승리팀 생존 포켓몬 HP 10% 회복과 PP·상태이상 이어받기는 종전 규칙을 보존한다.

## 저장 데이터 및 인터페이스
- 구버전 종합 power/ca/pa/gp 저장값은 포켓몬별 안정적 해시를 사용하여 6쌍 CA/PA로 결정적으로 이전한다.
- 게임 포켓몬의 level 필드는 이전 시 삭제한다.
- 구식 AI 구단 로직이 읽는 내부 power는 CA 평균에서 유도하는 호환 캐시이며 별도의 전투력 스탯이 아니다.
- 훈련·아카데미의 포켓몬 육성 효과는 PA 범위 안에서 특정 CA를 증가시킨다.
- 새 야생 포켓몬도 처음부터 개별 CA/PA만 생성한다.

## 확인된 검증과 남은 작업
- npm test, npm run check:web, 실제 브라우저 새 게임·훈련·Showdown 리그 한 경기 완료.
- 초기 균형식(0.80, 0.95, 0.70, 28)은 임시 밸런스 기준이므로 다중 시즌 대규모 테스트가 필요하다.
- 업스트림 Showdown은 팀 형식 호환을 위해 내부 기본 레벨 메타데이터를 계속 보유한다. 리그는 개별 레벨을 전달하지 않으며 전투 스탯과 핵심 피해 계산에는 해당 메타데이터를 사용하지 않는다.
- 일부 희귀한 기술의 내부 콜백(예: 셸사이드암 판정) 및 일격기 명중 규칙에는 업스트림 레벨 비교가 남아 있다. 모두 같은 내부 호환 기본값이라 개별 포켓몬의 성장에는 영향이 없지만, 원본 패키지의 모든 레벨 참조를 삭제한 완전한 포크는 아직 아니다.
